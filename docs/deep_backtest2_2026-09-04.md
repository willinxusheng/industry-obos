# 深度回测第二轮 · 量能与背离维度定界 + 展示层修正 · 2026-09-04

数据范围：31 个申万一级行业 × 1301 交易日（2021-04-27 → **2026-09-04 收盘**，较首轮追平 7 个交易日）。
方法：只读 data/，复用 compute.py PIT 管线；超额收益 = 行业 20d 收益 − 沪深300 同期 20d；
全部结论以超额端为准（首轮教训：绝对收益会被大盘 beta 污染）。
本地数据已由 fetch 追平至 09-04（腾讯源 31/31），官方口径复算：**combo 方向 67.6%（块级 p=0.0）、AUC 0.747、Brier 0.206**——模型在新增 7 日样本后依然稳健。

## 一、量能维度（首轮报告第七节建议 1，终于验证）

把成交量引入检验：量比 = 当日量 / 前 20 日均量（剔除当日，H7 口径），放量 ≥1.5 / 缩量 ≤0.7。

**量能 × 分数分桶 → 未来 20d 超额收益：**

| cs 分桶 | 放量 | 缩量 | 平量 |
|---|---|---|---|
| ≤20 深冷 | **+3.46%**（胜率 65.7%，n=105） | +0.46%（n=295） | +0.19% |
| 20-35 冷 | +0.19% | -0.22% | +0.13% |
| 35-50 偏冷 | +0.58% | +0.43% | -0.09% |
| 50-65 偏热 | **+1.10%** | **-0.70%**（胜率 37.7%） | +0.13% |
| 65-80 热 | +0.89% | 0.00% | +0.13% |
| ≥80 深热 | +0.37% | （样本不足） | +0.46% |

**关键发现（推翻生产规则）：**
1. **放量普遍 ≥ 缩量，几乎全分数段成立**——放量是"资金活跃"代理：深冷放量 = 恐慌盘换手充分后的反转，偏热放量 = 趋势延续。缩量（尤其缩量深冷）="无人接盘"，之后几乎不反弹（20d 超额≈0）。
2. **生产综合信号的两条量能规则方向全反**：
   - 原规则给「缩量 + 偏冷」加机会分（直觉"抛压枯竭"）→ 实测缩量超卖反弹最弱；
   - 原规则给「放量 + 偏热」减机会分（直觉"放量出货"）→ 实测偏热放量超额为正。
   - 且系数 0.3×0.3 = ±0.09 分，远够不到"机会/风险"标签边界，属**死权重**。
3. 稳健性边界：深冷+放量 n=105，70% 落在"市场冷"时段、2024 年集中 55 个——**方向可信但幅度不稳**，故只做"综合信号机会/风险微调分"（展示层），**不进 score/p_up 预测主链路**（与首轮"输出层饱和"结论一致）。

## 二、背离维度（UI「背离」列的第一次统计检验）

滚动复现生产 `detect_divergence`（前/后 120 日窗口 min/max 比较，bullish=价新低但分未新低，bearish=价新高但分未新高），逐日 PIT 标注，检验未来 5/20d 收益。

**20d 超额：**

| 信号 | 首轮（绝对收益） | 超额端（防伪） | 分市场 |
|---|---|---|---|
| 底背离 bullish（n=1422） | +3.00% | +1.02%（胜率 53.9%） | 市场中 **-0.65%** / 热 +2.04% |
| **底背离 + 深冷**（n=101） | **+7.56%** | **-0.16%（胜率 46.5%）** | 市场冷 -0.19% |
| 顶背离 bearish（n=1453） | +3.79% | +1.54%（胜率 57.3%） | 冷 +2.91% |
| **顶背离 + 热区**（n=284） | **+7.13%** | **+4.02%**（胜率 64.8%） | 市场热 +4.83% |
| 无背离 | -0.03% | +0.19% | — |

**窗口敏感性：** win=30 时 bull/bear 超额全负（-0.4/-0.6%）；win=60 时 bull +2.31%/bear +1.29%；win=120 时 +1.02%/+1.54%。**无任何窗口给出稳定且与 UI 语义一致的方向。**

**关键发现（修正 UI 语义）：**
1. 「底背离 + 深冷 +7.56%」折算超额后 **-0.16%**——完全是深冷 beta（首轮 D2 已知），背离无附加 alpha。
2. **「顶背离 = 注意风险」无任何数据支撑**：bearish 超额恒 ≥0；且 bearish 样本 90%+ 落在 2025-2026 牛市段（240 日窗口极值在震荡/熊市几乎不触发，一触发就是趋势行情）→ "顶背离后大涨"是**样本期选择 + 强者恒强**，不是背离信号有效。
3. 生产 `detect_divergence` 用 240 日窗口极值比较，本质度量的是"创 240 日新高/新低"的**趋势极值事件**，与经典"背离 = 动能衰竭"的局部摆动语义不是一回事。
